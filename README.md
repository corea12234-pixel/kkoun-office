# 🐾 꼬운 멍뭉이 AI 오피스

꼬운님 전용 데일리 오피스 — 루틴·회의실·체험단·핫딜·캘린더·메모를 한 화면에서 보는 모바일 퍼스트 정적 웹앱입니다.

- 주소: https://corea12234-pixel.github.io/kkoun-office/
- 구성: `index.html` 단일 파일 (HTML + CSS + 바닥부터 그린 강아지 SVG, 프레임워크·빌드 없음)
- 비서 4인: 짱아찌(말티즈) · 토코(시바견) · 팔릴까(푸들) · 쑥(비숑)

## 화면

| 탭 | 내용 |
| --- | --- |
| 📊 대시보드 | 오늘의 루틴 진행률, 비서 4인 출근 상태, 빠른 메모 |
| 💬 회의실 | 대회의실 · 지휘실 · 라운지, 비서 역할 카드, 지시 한 줄 기록 |
| 📝 체험단 | 진행 · 대기 체크리스트, 완료 토글, ⇅ 로 이동 |
| 🛒 핫딜·스레드 | 08·09·10·11시 핫딜방/스레드 체크, 시간대 메모 |
| 📅 캘린더 | 이번 주 월~일 일정 추가·삭제 |
| 📒 메모 | 자유 메모 + 체크리스트 |

## 저장 방식

서버가 없는 정적 앱입니다. 적은 내용은 브라우저의 `localStorage`(키 `kkounDogOffice.v1`)에만 저장되고,
기기·브라우저 사이에 자동으로 동기화되지 않습니다. 브라우저 기록을 지우면 함께 사라집니다.
매일 자정이 지나면 루틴 체크·핫딜 체크·출근 상태·빠른 메모만 초기화됩니다.

## 배포

GitHub Pages는 `gh-pages` 브랜치 루트에서 배포됩니다(`main`과 내용 동일하게 유지). `.nojekyll` 포함, 별도 빌드 단계 없음.
